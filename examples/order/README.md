# Пример процесса заказа

Этот пример показывает декларативную модель заказа без AXM-файла.

Сценарий:

1. `OrderCreated` создаёт заказ.
2. `PaymentCaptured` записывает платёж и переводит заказ в оплаченное состояние.
3. Изменение `Paid` запускает внешнюю операцию `SendReceipt`.
4. `Claim` запрещает оплату без `PaymentID` и отправку чека до оплаты.
5. Pebble сохраняет состояние и историю.
6. `ReplayFromHistory` восстанавливает состояние по журналу событий.

Поле `Total` хранит сумму целым числом в минимальных денежных единицах. Для реального приложения следует закрепить это соглашение отдельным доменным типом.

Запуск:

```bash
go run ./examples/order
```
