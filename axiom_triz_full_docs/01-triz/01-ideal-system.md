# Идеальная система Axiom по ТРИЗ

## Главная полезная функция

Axiom должен выполнять одну главную функцию:

```text
Позволить человеку описывать сложные durable-процессы простыми правилами,
а системе — самой безопасно исполнять, восстанавливать и объяснять эти процессы.
```

## ИКР — идеальный конечный результат

```text
Сложная система ведёт себя правильно,
хотя пользователь написал только простые правила и обычные функции.
```

Идеальная форма:

```text
Нет workflow-кода.
Нет FSM-взрыва состояний.
Нет ручной очереди задач.
Нет ручного retry.
Нет ручной идемпотентности.
Нет ручного replay.
Нет ручного explain/debug.

Есть:
  state
  event
  rule
  function
  always
```

## Что должно исчезнуть из головы пользователя

Пользователь не должен думать о:

```text
CRFG
computed/fact split
activity task queue
policy engine
claim checker
dependency indexes
fixpoint
history persistence shape
worker polling
```

Это всё должно жить внутри runtime.

## Что должен видеть пользователь

```text
Что есть в памяти системы?
Что случилось?
Когда правило может сработать?
Какую функцию вызвать?
Что записать в state?
Что нельзя нарушить никогда?
Почему правило сработало или не сработало?
```

## Формула идеальности

```text
Идеальность = полезность / (сложность + вред + стоимость + обучение)
```

Для Axiom:

```text
Идеальность растёт, когда:
  меньше DSL-сущностей видно пользователю;
  больше гарантий делает runtime;
  меньше ручного orchestration-кода;
  больше ошибок ловятся заранее;
  больше объяснений строится автоматически.
```

## Критерии идеальной версии

1. Пользователь может прочитать файл сверху вниз как описание поведения.
2. Каждое правило помещается в форму `when → do → then`.
3. Любая внешняя работа реализуется обычной Go-функцией.
4. State меняется только через `then`.
5. Safety выражается через `always`.
6. Runtime может ответить `why` и `why not`.
7. Replay не повторяет external effects.
8. Codegen делает compile-time boundary.
9. Studio показывает сценарии, а не runtime-механику.
10. Сложность есть, но она скрыта в нормализованном IR.
